COMP6452 26T2 Project 2 Task 3 — deployed smart contracts

Hyperledger Fabric has no account address as an account-based ledger such as
Ethereum does. A deployed contract is addressed by the tuple

    channel  ->  chaincode name  ->  contract name  ->  transaction name

and the installed package is separately identified by a package ID, which is a
deterministic SHA-256 hash of the chaincode package. Both are recorded below.

The contract name is part of the address here and not optional: batch-registry
hosts two contracts, so every client call in this project is qualified, e.g.

    contract.evaluateTransaction('BatchQueryContract:GetBatchHistory', batchId)

Platform : Hyperledger Fabric 2.5.16
Network  : fabric-samples test-network, CA-based (Org1MSP, Org2MSP, orderer)
Channel  : mychannel

Note: package IDs are content hashes of the installed package and will change
if the chaincode source or its build output changes. The two IDs above were
recorded from the deployment of the chaincode source in this archive. Read the
current IDs on a live network with:
    peer lifecycle chaincode queryinstalled
The deploy script also prints the ID it committed, on its last line.
